# 目录维护

左侧目录由 `_sidebar.md` 控制。

## 折叠分类写法

```markdown
- 总分类名称
  - [板子分类](/boards/stm32.md)
    - [具体型号 A](/boards/model-a.md)
    - [具体型号 B](/boards/model-b.md)
```

第一层是蓝色总分类，第二层是可以点击展开的分类，第三层是具体资料页面。

## 注意事项

- 文件路径建议使用英文、数字和短横线。
- 页面标题写在 Markdown 文件的第一个 `#` 标题中。
- 删除页面后，也要同步删除 `_sidebar.md` 里的链接。
